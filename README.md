**EitnyGameHub** объединяет библиотеку Steam, профиль игрока и подготовку игровых окружений в одном приложении для macOS. Проект предлагает открытый подход к задаче, которую решают программы класса CrossOver: запуск Windows-игр на Mac через слой совместимости.

Интерфейс написан на SwiftUI. За запуск Windows-приложений отвечает Wine, а перевод графики в Metal выполняют DXMT и D3DMetal. EitnyGameHub настраивает эти компоненты под конкретные игры и помогает управлять ими из привычного интерфейса macOS.

Это самостоятельный проект на ранней стадии. **Проверенные сценарии текущего выпуска — GWENT и первая Path of Exile в оконном режиме.** Наличие игры в библиотеке не означает подтверждённую совместимость. Сравнительных тестов производительности с CrossOver пока нет.

## Возможности

- **Библиотека Steam:** обложки, поиск, сортировка, установленные игры и время в игре.
- **Профиль игрока:** имя и аватар Steam без отдельного API-ключа.
- **Подготовка окружения:** загрузка нужных компонентов с проверкой контрольных сумм.
- **Профили игр:** отдельные настройки запуска и графики для GWENT и Path of Exile.
- **Нативный интерфейс:** SwiftUI, тёмное оформление, понятное боковое меню и иконка для Dock.
- **Установщик macOS:** установка приложения в «Программы» через стандартный мастер.
- **Открытый код:** сборка приложения, проверки и создание установщика доступны в репозитории.

## Совместимость

| Игра | Графика | Состояние в 0.4.1 |
| :--- | :--- | :--- |
| **GWENT: The Witcher Card Game** | DirectX 11 → DXMT → Metal | Вход и игра подтверждены автором; автоматический оконный режим, работают мышь и трекпад |
| **Path of Exile — первая часть** | DirectX 12 → D3DMetal → Metal | Экспериментальная поддержка; запуск и игра в окне подтверждены, доступен FSR |
| Остальные игры Steam | Зависит от игры | Отображаются в библиотеке; совместимость не проверена |

Проверки проводились на **MacBook Pro M3 Pro / macOS 27**. Другие модели и версии macOS ещё нуждаются в проверке. Совместимость не подразумевает гарантированную частоту кадров, работу античита или одинаковое поведение всех игровых режимов.

**Полноэкранный режим PoE пока нестабилен:** переключение в Fullscreen внутри игры приводило к чёрному экрану. Используйте обычное окно. Новый запуск сохраняет выбранные разрешение, FSR и ограничение кадров, возвращая оконный режим.

## Требования

| Компонент | Требование |
| :--- | :--- |
| Mac | Apple Silicon: M1 и новее; сборка arm64 |
| macOS | 14 и новее; для Path of Exile / D3DMetal — 15 и новее |
| Rosetta 2 | Требуется для Windows-окружения; устанавливается отдельно средствами macOS |
| Интернет | Для подготовки компонентов, входа в Steam и загрузки игр |
| Аккаунт | Собственный аккаунт Steam; для GWENT также вход в GOG внутри игры |
| Место на диске | Для окружения, Steam и выбранных игр |

Intel Mac в текущем выпуске не поддерживается. Установщик содержит только приложение: компоненты запуска, Steam и игры загружаются отдельно.

## Установка

1. Откройте [релиз 0.4.1](https://github.com/joineitny/EitnyGameHub/releases/tag/v0.4.1) и скачайте **EitnyGameHub-0.4.1-Installer.pkg**.
2. Запустите установщик и следуйте его шагам. Приложение появится в папке **«Программы»**.
3. Откройте EitnyGameHub и нажмите **«Подготовить Steam»**. Дождитесь загрузки компонентов.
4. Нажмите **«Открыть Steam»**, войдите в свой аккаунт и откройте библиотеку.
5. Установите нужную игру через Steam и обновите библиотеку в EitnyGameHub.

### Первый запуск GWENT

Установите GWENT в подготовленном Windows Steam, затем нажмите его карточку в EitnyGameHub. Приложение пропускает несовместимый REDlauncher и включает оконный режим. При запросе войдите в свой аккаунт GOG внутри игры.

### Первый запуск Path of Exile

Откройте раздел **Path of Exile → Подготовить PoE**. Он создаёт отдельное окружение со своим Steam. Войдите в него, установите **первую Path of Exile** и запускайте её кнопкой **«Играть в PoE»**.

Доступны три начальных пресета графики. Их применение требует закрытой игры и создаёт резервную копию настроек; звук и управление сохраняются. Обычный запуск не заменяет выбранные вами разрешение и FSR. Окружение GWENT остаётся отдельным.

### Если macOS блокирует открытие

Приложение имеет локальную ad-hoc подпись. **Установщик не подписан Developer ID, а выпуск пока не заверен Apple.** После попытки открытия проверьте **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно** для загруженного EitnyGameHub. [Инструкция Apple](https://support.apple.com/102445). Отключать защиту macOS целиком не требуется.

Если отображается другая ошибка, приложите её точный текст к сообщению в Issues. Установщик сам по себе не устраняет все возможные ошибки совместимости.

## Библиотека и данные

Библиотека строится по **локальным данным Steam**, а не по непрерывному запросу облачных лицензий. После покупок, смены аккаунта или установки игры откройте библиотеку в Steam и обновите список в EitnyGameHub. Для некоторых аккаунтов кеш может быть неполным или устаревшим; окончательный список доступных игр показывает Steam.

Вход выполняется в официальном клиенте Steam. EitnyGameHub не запрашивает пароль Steam в собственном интерфейсе. Обложки используются из кеша Steam или его CDN, аватар — из публичного профиля Steam.

На новом Mac игровые данные по умолчанию находятся здесь:

```text
~/Library/Application Support/EitnyGameHub
```

Обновление приложения не удаляет эту папку. **Не передавайте её другим пользователям:** в окружении Steam могут храниться данные входа. Для передачи приложения достаточно установщика из Releases.

Поддерживается переносимая папка `EitnyGameHub Data` рядом с приложением с пустым файлом `.portable`. Старые папки `GwentBridge Data` и настройки прежних версий также распознаются. Для разработки можно явно задать абсолютный путь через `EITNY_GAMEHUB_DATA`.

## Решение проблем

| Ситуация | Что сделать |
| :--- | :--- |
| Библиотека пуста или устарела | Открыть Steam, перейти в библиотеку, затем обновить список в EitnyGameHub |
| После обновления нет доступа к данным | **Настройки → Разрешить доступ к папке**, выбрать папку данных приложения |
| PoE зависла после переключения экрана | Переключиться через ⌘Tab в EitnyGameHub → Path of Exile → **Восстановить оконный режим…**; текущий сеанс PoE будет закрыт |
| Не найден компонент запуска | Проверить Rosetta 2 и подключение к интернету; повторить подготовку |
| Другая ошибка | Создать [Issue](https://github.com/joineitny/EitnyGameHub/issues), указав модель Mac, macOS, игру, действия и текст ошибки |

Перед публикацией журналов удаляйте личные пути, имена аккаунтов, токены и другие персональные данные. Полную папку Steam прикладывать не нужно.

## Сборка из исходников

Нужны Mac с Apple Silicon и Apple Command Line Tools. Проверенная среда сборки: Swift 6.4, режим языка Swift 5, deployment target macOS 14.

```sh
git clone https://github.com/joineitny/EitnyGameHub.git
cd EitnyGameHub
bash build.sh
bash test.sh
```

Приложение создаётся рядом с папкой исходников: `../EitnyGameHub.app`. Тесты используют временные данные; они проверяют границы запуска, парсеры Steam, изоляцию окружений и сохранение настроек игр.

Чтобы создать установщик из собранного приложения:

```sh
bash package.sh
```

Результат появится в `../Installer-0.4.1/`. Упаковщик проверяет список файлов, содержимое распакованного приложения, подпись, архитектуру и права запуска. Сертификат Developer ID и заверение Apple в этот процесс пока не входят.

### Устройство проекта

```text
Sources/       SwiftUI-приложение, библиотека Steam, настройки игр
Resources/     Запуск Steam, игровые профили и иконки
Tests/         Проверки парсеров и настроек
Installer/     Сборка и проверка PKG-установщика
build.sh       Сборка приложения
test.sh        Проверки без запуска реальных игр
package.sh     Создание установщика
```
