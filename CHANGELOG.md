# Changelog

[English](#english) · [Русский](#русский)

## English

### 0.4.1 — 2026-09-26

First public release of EitnyGameHub. Promoted to Latest on September 26, 2026; the installer and application code were unchanged by that status update.

- Native Steam library with profile, cover art, search, sorting and playtime.
- Working GWENT profile with REDlauncher bypass and automatic windowed mode.
- Separate environment for the first Path of Exile with DirectX 12 / D3DMetal.
- Initial PoE presets and preservation of user resolution and FSR settings.
- PoE windowed-mode recovery that closes only the PoE process.
- Standard macOS PKG installer with first-run instructions.
- Application source, checks and installer build tooling in the repository.

Tested by the project creator on M3 Pro / macOS 27. PoE Fullscreen remains unstable.
The installer is not Developer ID signed or notarized by Apple; macOS may require a per-file opening exception.

## Русский

### 0.4.1 — 2026-09-26

Первый публичный выпуск EitnyGameHub. 26 сентября 2026 назначен основным релизом Latest; установщик и код приложения при смене статуса не изменялись.

- Нативная библиотека Steam: профиль, обложки, поиск, сортировка и время в игре.
- Рабочий профиль GWENT: пропуск REDlauncher и автоматический оконный режим.
- Отдельное окружение первой Path of Exile с DirectX 12 / D3DMetal.
- Начальные пресеты PoE, сохранение пользовательских настроек разрешения и FSR.
- Восстановление оконного режима PoE с закрытием только её процесса.
- Стандартный PKG-установщик для macOS с инструкциями первого запуска.
- Исходный код, проверки и сборка установщика доступны в репозитории.

Проверено автором на M3 Pro / macOS 27. Fullscreen в PoE пока нестабилен.
Установщик не имеет Developer ID / заверения Apple; отдельное разрешение macOS может потребоваться.
