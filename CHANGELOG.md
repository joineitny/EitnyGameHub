# Changelog

## 0.4.1 — 2026-09-26

Первый публичный выпуск EitnyGameHub (Early Access).

- Нативная библиотека Steam: профиль, обложки, поиск, сортировка и время в игре.
- Рабочий профиль GWENT: пропуск REDlauncher и автоматический оконный режим.
- Отдельное окружение первой Path of Exile с DirectX 12 / D3DMetal.
- Начальные пресеты PoE, сохранение пользовательских настроек разрешения и FSR.
- Восстановление оконного режима PoE с закрытием только её процесса.
- Стандартный PKG-установщик для macOS с инструкциями первого запуска.
- Исходный код, проверки и сборка установщика доступны в репозитории.

Проверено автором на M3 Pro / macOS 27. Fullscreen в PoE пока нестабилен.
Установщик не имеет Developer ID / заверения Apple; отдельное разрешение macOS может потребоваться.
